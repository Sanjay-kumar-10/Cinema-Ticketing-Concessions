# Cinema Ticketing and Concessions

## Project Description
A menu-driven Java console application for managing cinema shows, ticket bookings, seat availability, cancellations, and concession orders.

## Features
- Display available movie shows.
- Book tickets and select seats.
- Prevent double-booking.
- Confirm payment before finalizing bookings.
- Cancel bookings and release seats.
- Order popcorn, Coke, and nachos.
- Display booking and concession receipts.
- Display booked seats.
- Handle invalid inputs and errors.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Java Collections Framework
- Exception Handling
- Eclipse IDE

## Project Structure
- `main` – Main application and test classes.
- `model` – Movie, Screen, Show, Seat, Customer, Booking, and ConcessionOrder classes.
- `service` – BookingService and ConcessionService classes.

## How to Run
1. Open the project in Eclipse IDE.
2. Open `Main.java` inside the `main` package.
3. Run it as a Java Application.
4. Follow the menu displayed in the console.
